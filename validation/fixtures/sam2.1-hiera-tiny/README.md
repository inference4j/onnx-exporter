# SAM 2.1 Hiera Tiny reference fixtures

These fixtures are generated by `validation/sam2_validate.py` from two deterministic,
synthetic images. They cover:

- one foreground point;
- foreground and background points in one prompt;
- one box;
- one box plus one foreground point.

Coordinates in the case JSON files are in original-image pixels. Each case records the
three ONNX `iou_scores`, selected mask index, `object_score_logits`, and the path to the
post-processed binary mask at the original image size.

The images are original geometric drawings produced by the validation script and may be
used under this repository's license.
